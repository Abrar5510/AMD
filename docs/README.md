## The 5 rules that matter most

1. **AMD is mandatory.** A meaningful part of the working product must run on AMD infrastructure, and it must be visible in the demo. No AMD → not eligible for prizes.
2. **It must work.** Judges want a working product solving a real problem for a real user — not just slides or a dashboard.
3. **Register in three places:** lablab.ai, the lablab.ai Discord, and the **AMD AI Developer Program** (required for approval).
4. **Submit everything:** public GitHub repo, demo video, pitch slides, cover image, live app URL. See the [checklist](05-submission-and-judging.md).
5. **Original + MIT-compliant.** Never commit API keys — use environment variables.
