# 05 — Submission & Judging

## Submission checklist

### 📋 Basic information
- [ ] Project title
- [ ] Short description
- [ ] Long description
- [ ] Technology & category tags
- [ ] Selected challenge (track)

### 📸 Cover image & presentation
- [ ] Cover image
- [ ] Video presentation (demo video)
- [ ] Slide presentation (pitch deck)
- [ ] Clear explanation of **the problem** and **the intended user**

### 💻 App hosting & repository
- [ ] Public GitHub repository
- [ ] Demo application platform (where it's hosted)
- [ ] Application URL
- [ ] Working prototype

### 🔒 Hygiene (all tracks; explicitly required for Evolus)
- [ ] No API keys or secrets in the repo — environment variables only
- [ ] README that actually runs
- [ ] Containerized app (required for the Evolus track)
- [ ] Original work, MIT-compliant

### ✅ AMD proof
- [ ] The demo clearly shows the AMD-powered part of the product working

## Track-specific demo items

| Track | Must also show |
|-------|----------------|
| 1. Intelligent Industry | Realistic industrial data → alert / explanation / recommendation / action; who uses it; what improves |
| 2. Health & Wellbeing | First input → final result; visible uncertainty; human hand-off; your answers on the 5 safety risks |
| 3. Reinvent Commerce | Data → recommendation/action; how any forecast is calculated (not LLM-only) |
| 4. New Kind of Experience | ≥2 audiences/inputs; team vs model contributions; quality control; cost per experience; who pays |
| Evolus | Evolus workspace with your AMD vLLM endpoint, ≥2 building blocks, API calls from your app |

## Judging criteria (main hackathon)

| Criterion | What judges ask |
|-----------|-----------------|
| **Application of Technology** | How effectively are the chosen model(s) integrated into the solution? |
| **Presentation** | How clear and effective is the presentation? |
| **Business Value** | What is the impact and practical value, and how well does it fit a business area? |
| **Originality** | How unique and creative is it; does it demonstrate interesting behaviours? |

Partner-specific criteria:
- **Evolus track** → same four criteria, interpreted for Evolus. See [tracks/evolus-business-agents.md](tracks/evolus-business-agents.md#judging-evolus-track).
- **Vibe Generation Special Prize** → Hybrid / Becreatives / Vibe Generation. See [04-prizes.md](04-prizes.md#vibe-generation-special-prize--airpods-5-for-the-whole-team).
