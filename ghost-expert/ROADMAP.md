# Ghost Expert roadmap

Work that needs the physical world: a real machine, a camera, the AMD GPU box, or people. Desk work that can be done now is in [../docs/14-investor-plan.md](../docs/14-investor-plan.md).

## Phase 1 — Make it real (weeks 1–2)

- [ ] Pick a real job on a real machine (workshop press, HVAC filter change, pump), not props.
- [ ] Film the expert doing it once, narrating ("First / Next / Now / Then / Finally").
- [ ] Film at least 10 trainee runs: 5 clean, plus skip step 4, skip step 3, and steps 5 and 6 swapped. Include gloves, poor lighting and two camera angles on purpose.
- [ ] Run Gate 1 (`scripts.eval_verify`), Gate 2 (`scripts.run_eval`) and latency (`scripts.smoke_gemma`) on the AMD box. Put the numbers in the README Results table, including the bad ones.
- [ ] Gate 3: a person who hasn't seen the code does the job 3 times under the coach.
- [ ] Test "try it yourself" mode and the phone camera end to end on the box.

## Phase 2 — The demo (weeks 2–3)

- [ ] Film demo v2 from the shot list, using real footage and real screen recordings.
- [ ] Host the "try it yourself" link on the box behind `APP_TOKEN`.
- [ ] Build the meeting kit: replay recording, recorded backup video, one-click reset.
- [ ] Rehearse until a full live run takes under 3 minutes.

## Phase 3 — Customers (weeks 3–8)

- [ ] Interview 15–20 plant training, EHS and quality managers.
- [ ] Sign 2 design partners.
- [ ] Run 1 paid pilot on one procedure. Measure time to competence and errors, before and after.
- [ ] Collect LOIs.
- [ ] Trial an on-site box at one plant so video never leaves the site.

## Phase 4 — Raise (week 8+)

- [ ] Replace every `[PENDING]` slide in the deck with filmed eval and pilot numbers.
- [ ] Start investor meetings with the demo v2 film and the live link.
